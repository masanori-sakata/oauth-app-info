Privacy Policy

Last updated: 2026-11-07

English

  • gmail-multi is a personal tool used only by its developer with the developer's own Google accounts.
  • It accesses Gmail data (messages, labels, drafts) through the Gmail API solely to let the developer read, search, draft, and send their own email.
  • It accesses Google Calendar data (calendar list and events) through the Google Calendar API solely to let the developer view, create, update, and delete events on their own calendars.
  • The tool runs on the developer's local computer. When the developer asks an AI assistant (Claude by Anthropic) to work with their email or calendar, the relevant Gmail or Calendar data is passed to that assistant only to carry out the developer's request. Gmail and Calendar data is not stored on any server operated by the developer, is not sold or shared with any other party, is not used for advertising, and is not used to train generalized AI models.
  • OAuth tokens are stored only on the developer's local computer.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at https://myaccount.google.com/permissions.

日本語

  • gmail-multi は、開発者本人が自分の Google アカウントでのみ使用する個人用ツールです。
  • Gmail API を通じて Gmail のデータ（メッセージ・ラベル・下書き）にアクセスし、本人のメールの閲覧・検索・下書き作成・送信にのみ使用します。
  • Google Calendar API を通じて Google カレンダーのデータ（カレンダー一覧・予定）にアクセスし、本人のカレンダーの予定の閲覧・作成・変更・削除にのみ使用します。
  • 本ツールは開発者のローカル PC 上で動作します。開発者が AI アシスタント（Anthropic 社の Claude）にメールやカレンダーに関する作業を指示した場合に限り、その作業に必要な Gmail・カレンダーのデータをアシスタントへ渡します。これらのデータを開発者のサーバーへ保存することはなく、他者への販売・共有、広告への利用、汎用 AI モデルの学習への利用は行いません。
  • OAuth トークンは開発者のローカル PC にのみ保存されます。
  • Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（Limited Use 要件を含む）に従います。
  • アクセス許可は https://myaccount.google.com/permissions からいつでも取り消せます。
